# 高校科研项目申报与管理系统 - 启动指南

## 一、后端启动（Django）

### 1. 安装依赖
```bash
cd backend
pip install -r requirements.txt
```

### 2. 创建 MySQL 数据库
在 MySQL 中执行：
```sql
CREATE DATABASE research_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3. 修改数据库配置
打开 `backend/research_system/settings.py`，修改数据库密码：
```python
DATABASES = {
    'default': {
        ...
        'PASSWORD': '你的MySQL密码',
        ...
    }
}
```

### 4. 数据库迁移
```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. 初始化示例数据（含4个测试账号）
```bash
python init_data.py
```

### 6. 启动后端服务
```bash
python manage.py runserver 8000
```

---

## 二、前端启动（Vue3）

```bash
cd "Django-Management web"
npm install
npm run dev
```
访问：http://localhost:5173

## 四、接口说明

| 方法   | 路径                          | 说明                   | 权限       |
|--------|-------------------------------|------------------------|------------|
| POST   | /api/login/                   | 登录，返回 JWT Token   | 公开       |
| POST   | /api/register/                | 注册                   | 公开       |
| GET    | /api/user/info/               | 获取当前用户信息       | 登录后     |
| GET    | /api/projects/                | 项目列表（分页/搜索）  | 登录后     |
| POST   | /api/projects/                | 提交项目申报           | 教师       |
| GET    | /api/projects/{id}/           | 项目详情               | 登录后     |
| PUT    | /api/projects/{id}/           | 修改项目（待审核中）   | 申报人     |
| POST   | /api/projects/{id}/audit/     | 提交审核意见           | 专家/管理员|

### 查询参数（GET /api/projects/）
- `search=关键词`      搜索项目名称/申报人/学院
- `status=pending`     按状态筛选（pending/approved/rejected）
- `page=1`             页码
- `page_size=10`       每页条数
